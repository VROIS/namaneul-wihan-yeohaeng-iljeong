### 1-4. 내손앱(Neon) → Supabase 데이터 이전 (핵심)

> **현황 (4/7 확인)**: 내손앱은 Replit Neon DB, nubi는 Supabase — **2개 DB 분리 상태**
> - 내손앱 서버: `my-handyguide1.replit.app` → Neon PostgreSQL
> - nubi 서버: `legal-dannye-dbstour-4e6b86d5.koyeb.app` → Supabase PostgreSQL
> - 통합 목표: Supabase 단일 DB (백서 §2 인프라 결정)
> - 스키마는 `shared/schema.ts`에 이미 46개 테이블 통합 완료
> - **데이터만 이전하면 됨**

| 테이블 | 건수 | 중요도 | 메모 |
|--------|------|--------|------|
| users | 66명 | 핵심 | google 35, kakao 30, replit 1 |

| voice_configs | 0건 | — | 비어있음 |

**✅ DB 구조 확정 (4/7 조사 결과) — 이미 통합 완료:**

```
내손앱 Replit (my-handyguide1.replit.app)  ──┐
  2026-01 이전: 구 Neon (ep-long-flower) 사용  │  ← 폐기됨
  2026-01 이후: Supabase 전환 완료             │
                                              ├──→  Supabase (단일 DB)
nubi Koyeb (legal-dannye-...koyeb.app)     ──┘      cities 111건
                                                     places 1,790건
  내손앱 + nubi = 이미 같은 Supabase 사용              place_seed_raw 6,896건
                                                     users 12명+ 활성
                                                     guides 214건
                                                     prompts 14건
                                                     weather_sync 매시간
```

- **데이터 이전 불필요** — 내손앱이 2026-01부터 이미 Supabase 사용 중
- 구 Neon(`ep-long-flower`) = 폐기된 인스턴스 (83건, 2026-01-21 이후 데이터 없음)
- Koyeb `/api/admin/guides` 404는 라우트가 없을 뿐, DB에 데이터는 있음
- `p0-data-migrate.js`의 Neon URL = 구버전 → 실행 불필요
