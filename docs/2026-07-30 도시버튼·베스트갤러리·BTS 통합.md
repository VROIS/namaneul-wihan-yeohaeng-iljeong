##### ⑦-2 사장님 실기기 지적 2건 해소 (2026-08-03)

**㉠ 사진 없는 장소 = 새까만 화면 + 작은 아이콘** → 사장님: "**아이콘이 거의 화면을 다 채워야 함 · 뒷배경 완전 투명 · 검정색은 여행앱의 금기색**". 원형도 **투명 위 텍스트 오버레이**다.
→ 검정(`container` 의 `#000`)을 **사진이 깔릴 때만** 적용하도록 옮기고, 사진 없으면 이 파일이 이미 쓰던 밝은 값(`#FFFEFA`, 음성 모드 값 재사용 = 새 색 0)으로. 아이콘은 **화면 폭 80% + 옅게**(글이 먼저 읽힘), 문장은 **이미 있던 `sentenceDark`** 재사용. 하이라이트(제미니 블루)·글자 크기·행간·버튼은 무수정.
**사진이 있을 때는 100% 종전 그대로.** → 사장님 실기기 확인 = **"이게 낫다"(승인)**.

**㉡ 저장 후 낭독이 1단락만 읽고 끝남** → 브라우저에서 음성 호출을 직접 기록해 **원인 확정**(추측 아님):

```
+32.3s speak  당시 왕립 군사학교의…
+34.8s CANCEL                    ← [저장] = pauseTTS 의 Speech.stop()
+34.8s speak  저장되었습니다
+34.8s error:interrupted 당시…   ← 우리가 멈춘 것인데 '오류'로 들어옴
+36.9s speak  당시 왕립 군사학교의…  ← 재개
        (여기서 끝 = 사슬 끊김)
```

`speakSentence` 의 `onError` 가 `advanceRef=false` 로 사슬을 끊고 있었다. **[저장]·[일시정지]가 부른 정지는 오류가 아니다** → `onDone` 이 쓰는 것과 **같은 가드 1벌**(`if (pausedRef.current) return`)을 `onError` 에도 적용.
수정 후 재현 = `…speak 백화점이 아니라…` **다음에 `speak 이 건물의 상징인 거대한 유리…` 가 이어짐 = 사슬 유지 확인.**
⚠️ 이건 이번 세션이 만든 결함이 아니라 **클론에 원래 있던 것**이다(원형은 저장 시 낭독을 아예 정지시켜 이 경로가 없다).

**원형 대조로 확정한 사실** — 아래 셋은 **원형(내손앱 `dist/public/index.js`)에 없고**, 2026-07-21 사장님 지시로 추가된 **우리만의 개선**이다. 원형에서 답을 가져올 수 없으므로 앞으로도 우리 것을 정본으로 본다.

| | 원형 | 우리 |

| "이미 저장되었습니다" | **문구 자체가 없음** | 있음 |
| 저장 중복 방지 | **없음** | 있음(2026-08-03 = 창고 `mine` 과 연결) |
