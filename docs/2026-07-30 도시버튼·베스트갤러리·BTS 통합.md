## 2. 사장님 결정 (2026-07-30, 구속력)

1. **도시 버튼 = 서버가 DB 실측으로 동적 노출**(≥300행, 완비순). 지금 5개 → 발굴하면 자동 증가
2. **대표여정 = 사장님이 직접 선정해 올리는 "베스트 갤러리."** AI 임의 생성 금지. **저는 올리는 장치만**
3. **미리보기 레이아웃 = 사장님 결정.** 저는 **가짜 데이터를 진짜로 바꾸는 것만**
4. **BTS 지구본 = 남은 공연도시 DB 동적화.** 8장 화면 상단 도시명과 **같은 소스 연동**
5. **BTS 생성기 = 메인앱 1벌.** 왕복 = **항상 공연장 출발↔도착**
6. **BTS 는 메인앱보다 단순 = 1인 · 1일.** **비용 필드는 별 소용 없음** — 어차피 장소와 위치를 보여주는 것이 목적
7. **`BTSLoading` 화면 = 삭제**(불필요)
8. **`ReelCard` 이미지 = 살림.** 지금은 위키 사진이 많지만 발굴하며 구글 이미지로 교체될 것이므로 **표시를 유지**
9. **AI의견 탭 = BTS 에서도 활성화.** 어차피 크레딧 차감됨. 백엔드 = **메인앱과 같은 엔드포인트·같은 프롬프트, 화면 맥락(헤더)만 다르게**
10. **인증 = 껍데기만 다른 새 창, 요소 동일.** 순서 = **생년월일 → 구글 → 카톡 → 애플 → 메일.** 애플 = **iOS 노출 / AOS 비노출, 공간은 확보**
11. **하단 5단 = 메인앱과 동일 구현 + 어디서나 고정**(예외 = 지구본·아미봉). 마케팅 특화
12. **번들ID = `com.sonanie.guide`**(내손앱은 다른 기기에서 볼 수 있고 **덮어도 무관**). **iOS 빌드도 제가 함**
13. 결제 예외처리(환불·경합) = 상용화 전이므로 미룸
