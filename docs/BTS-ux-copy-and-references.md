### 1.2 디자인 패턴 참고

| 패턴 | 소스 | 참고할 점 |
|------|------|----------|
| 캐릭터 선택 캐러셀 | Dribbble "character selection" | 수평 스크롤, 선택 시 글로우 |
| 퀴즈/성격 선택 | Mobbin quiz screens (1,900+) | 풀스크린, 즉시 피드백, 프로그레스 |
| 카드 기반 장소 탐색 | Behance "card carousel app UI" | 비주얼 퍼스트, 그라데이션 오버레이 |
| 여행 타임라인 | Pinterest "travel app UI" | 수직 타임라인, 컬러코딩 |

### 1.3 핵심 디자인 원칙 (레퍼런스에서 도출)

1. **비주얼 퍼스트**: 이미지와 캐릭터가 주인공, 텍스트는 보조
2. **즉시 피드백**: 탭하면 바로 반응 (스케일, 글로우, 진동)
3. **프로그레스 표시**: 항상 사용자가 "어디에 있는지" 알 수 있게
4. **게이미피케이션**: 쇼핑하듯 모으는 느낌, 뱃지/게이지
5. **밝고 깨끗한 테마**: 화이트 베이스 + 캐릭터 컬러 포인트

## 2. UX 카피 — 전체 화면별

### Voice & Tone 가이드
- **타깃**: MZ세대 + ARMY (20-30대)
- **톤**: 친근하고 재미있게, 하지만 유치하지 않게
- **언어**: 한국어 메인 + 영어 서브
- **이모지**: 적절히 사용 (과하지 않게)
- **금지**: 존댓말 너무 딱딱하게, "~합니다" 반복

---

### Scene 1: 캐릭터 선택

#### 헤더
- **타이틀**: `나만의 방탄 투어`
- **서브타이틀**: `Choose your travel persona`

#### 캐릭터 카드 카피

| 캐릭터 | 한국어명 | 영문명 | 설명 (1줄) |
|--------|---------|--------|-----------|
| 컬렉터 | 컬렉터 | Culture Collector | 미술관, 갤러리, 역사 명소를 수집하듯 여행하는 문화 탐험가 |
| 로맨티스트 | 로맨티스트 | Romantic Wanderer | 석양과 카페를 찾아 떠나는 감성 여행가 |
| 익스플로러 | 익스플로러 | Aesthetic Explorer | SNS 핫플을 직접 찾아가 인증하는 트렌드세터 |

| 칠러 | 칠러 | Ultimate Healer | 자연 속에서 느긋하게 영혼을 충전하는 미니멀 여행가 |

#### CTA 버튼 상태
| 상태 | 카피 |
|------|------|
| 미선택 | `캐릭터를 선택하세요` (비활성) |
| 선택됨 | `{캐릭터명} 바이브로 시작하기 ✨` |

#### 인터랙션 카피
- 카드 탭 시: 카드가 확대 + 보더 글로우
- 캐러셀 힌트: 첫 진입 시 좌우 바운스 애니메이션

---

### Scene 2: 장소 카트 (바이브 스팟)

#### 헤더
- **타이틀**: `{캐릭터명}의 바이브 스팟`
- **서브타이틀**: `{n}/8 선택됨 · 2개 이상 골라주세요`

#### 도시 칩
- 활성: 선택된 도시명 (캐릭터 컬러)
- 비활성: 나머지 도시들

#### 서라운드 카드
- 각 카드: `{이모지}` + `{장소명}` + `{가격}`
- 선택됨: 체크 배지 (✓) + 캐릭터 컬러 보더

#### 게이지 바
| 상태 | 카피 |
|------|------|
| 0개 | `0 / 8` |
| 1개 | `1 / 8 · 하나 더!` |
| 2-7개 | `{n} / 8` |
| 8개 | `8 / 8 · 풀코스!` |

#### CTA 버튼 상태
| 상태 | 카피 |
|------|------|
| 2개 미만 | `2개 이상 골라주세요` (비활성) |
| 2개 이상 | `AI 동선 최적화 🧠` |

#### Empty State (장소 로딩 실패)
- **타이틀**: `장소를 불러올 수 없어요`
- **설명**: `네트워크 상태를 확인하고 다시 시도해주세요`
- **CTA**: `다시 시도`

---

### Scene 3: 로딩 (AI 동선 생성)

#### 로딩 메시지 순서 (각 1.2초)
| 순서 | 이모지 | 메시지 |
|------|--------|--------|
| 1 | 🎵 | 바이브 동기화 중... |
| 2 | 🗺️ | 경로 최적화 연산 중... |
| 3 | 📡 | 현지 정보 스캔 완료! |
| 4 | ☁️ | 날씨·교통 체킹 완료 |
| 5 | ✨ | 최종 동선 생성 완료! |

#### 하단 정보
- `{도시명} · {캐릭터명} · {n}곳`

#### Error State (생성 실패)
- **타이틀**: `동선 생성에 실패했어요`
- **설명**: `다시 시도해 볼까요?`
- **CTA**: `다시 시도` / `돌아가기`

---

### Scene 4: 대시보드

#### 헤더
- **타이틀**: `나만의 방탄 투어`
- **우측**: 공유 아이콘 (↗)

#### 릴스 섹션
- **섹션 타이틀**: `미리보기`
- **섹션 서브**: `스와이프해서 장소를 탐색하세요`
- 각 릴스 카드: `{시간}` + `{장소명}` + `{캐릭터명} 바이브에 딱 맞는 추천 장소`

#### 타임라인 섹션
- **섹션 타이틀**: `스마트 타임라인`
- **섹션 서브**: `{도시} · {n}곳 · {캐릭터명} 바이브`
- 각 타임라인 카드: `{장소명}` + `{시간}` + `{가격}` + 추천 이유

#### 추천 이유 템플릿
| 카테고리 | 추천 이유 카피 |
|---------|---------------|
| attraction | 💡 {캐릭터명} 스타일에 최적화된 문화 스팟 |
| healing | 💡 여행 중 리차지할 수 있는 힐링 포인트 |
| restaurant | 💡 현지인이 추천하는 맛집 코스 |
| hotspot | 💡 인스타 감성 터지는 인증샷 명소 |
| adventure | 💡 아드레날린 폭발하는 액티비티 스팟 |

#### 요약 카드
- **타이틀**: `📊 여행 요약`
- 항목: `{n}곳` (장소) / `{h}h` (예상 시간) / `₩{금액}` (예상 비용)

#### 하단 액션
| 버튼 | 카피 | 스타일 |
|------|------|--------|
| Secondary | `처음부터 다시` | 아웃라인 |
| Primary | `🗺️ 이 일정 공유하기` | 브랜드 그라데이션 |

#### 공유 텍스트 템플릿
```
✨ 나만의 방탄 투어 ✨
🎭 {캐릭터명} 바이브
📍 {도시} · {n}곳

{장소1} → {장소2} → {장소3}...

NUBI 앱에서 나만의 투어 만들기!
```

## 3. 확인 다이얼로그

### 리셋 확인
- **타이틀**: `처음부터 다시 할까요?`
- **설명**: `선택한 캐릭터와 장소가 모두 초기화돼요`
- **Primary**: `다시 시작`
- **Secondary**: `취소`

### 장소 최대 선택 알림
- **토스트**: `최대 8곳까지 선택할 수 있어요`
- 1.5초 후 자동 사라짐

## 4. 마이크로 인터랙션 카피

| 인터랙션 | 피드백 |
|---------|--------|
| 캐릭터 선택 | 카드 스케일업 + 글로우 (무음) |
| 장소 추가 | 카드 체크 + 게이지 채움 (haptic) |
| 장소 제거 | 카드 언체크 + 게이지 줄어듦 |
| AI 로딩 시작 | 카드들이 중앙으로 빨려들어감 |
| 대시보드 진입 | 릴스 카드 순차 페이드인 |
| 공유 완료 | `✅ 공유되었어요!` 토스트 |

| CTA 버튼 | `{버튼 텍스트}. {활성/비활성}` |
| 릴스 카드 | `{장소명}, {시간}. 스와이프하여 다음 장소 보기` |
