## 2. 딥링크 = 출발지+경유지+도착지 **왕복** (사장님 SSOT 2026-07-24)

- **출발/도착(origin=destination = 왕복)**:
  - **숙소 변경시** = 숙소명+좌표+placeId. (숙소 변경하면 지도 마커·슬롯 즉시 재배열 = 클릭 시점이 사용자 최종 요구.)
  - **미설정** = **도시명 텍스트**("Paris") = 구글맵이 알아서 도시 중심으로 지오코딩. = 좌표 조회 불필요·견고(우리 문제 발생해도 구글이 처리, 사장님 SSOT).
- **경유지(waypoints)** = 그 날 슬롯(클릭 시점 화면 순서, 재정렬 안 함). PSR 조회로 PID+이름 보충.
- **규격**(공식): `maps/dir/?api=1&travelmode=driving` + origin/destination(+`*_place_id`) + waypoints(이름/좌표)+`waypoint_place_ids`(전원 PID 시 1:1). 경유지 상한 9(초과 절삭). 구글맵 앱 없는 모바일 브라우저 = 3개 제한(한계).
- **라벨 언어 = 구글 통제**: place_id 있으면 구글이 우리 텍스트 무시하고 공식명을 기기 언어로 표시(한국어 폰=유명지 한국어, 나머지 로컬/영어). hl=ko 무관 = 실증. 우리 텍스트는 place_id 실패 시 폴백(로컬명 = 오매칭 방지, "한국어명→콜마르 450km" 실증).

## 4. 이번 상황 기록 (사장님 실클릭 → 왕복·도시명·버튼 재구성)

사장님이 로컬 크롬에서 직접 바로가기를 눌러 두 가지 결함을 실증 지적:
1. **출발/도착지가 슬롯으로 나옴** = 왕복(출발지+도착지) 미구현. 우리 앱 디폴트 출발/도착 = 도심중심, 숙소 변경 시 그게 기준(지도 마커·슬롯 즉시 반영)인데 딥링크에 미반영. 구글맵 최대 = 출발1+경유9+도착1=11 = 우리 일일 슬롯수와 정합.
2. **버튼 텍스트가 설명형("1일차 동선 바로가기")** = 넘침·군더더기. 아이콘+"바로가기"면 충분.

**해결**:
- **딥링크 왕복** = 출발/도착 = 숙소(변경시) ?? 도시명 텍스트(미설정). 경유지 = 슬롯.
  - 도심중심 좌표 확보 방식 검토 → **도시명 텍스트로 구글이 알아서**(사장님 SSOT = 간단·견고, 좌표 조회 불필요). Routes API도 도시명 주소 지원 = 왕복 실소요 계산됨.
- **버튼 설명형 제거** = "바로가기"/"바로 예약하기" + CLAUDE.md §23 헌법 명시(설명형 버튼 금지, 이모지 금지와 일맥) + 메모리 [[feedback_no_descriptive_button_text]].

**실증(로컬 크롬 딥링크 캡처)**:
- 숙소 설정(풀만 파리 타워 에펠) → origin=destination=**풀만 파리 타워 에펠** 왕복 ✅
- 숙소 미설정 → origin=destination=**"Paris"**(도시명) 왕복 + 경유지 9 ✅
- 버튼 텍스트 = "바로가기"/"바로 예약하기"(n일차 없음) ✅
- 백엔드 실소요: 도시명 주소 왕복 1시간 44분·23.8km / 숙소 좌표 왕복 1시간 58분 ✅

## 6. 비용 = 바로가기 클릭 시 Routes API 1콜만 유료

| 동작 | 외부호출 | 비용 |
|---|---|---|
| 바로 예약하기(전문가 문의함 통합) | 없음(내부 DB) | **무료** |
| 바로가기 → 구글맵 딥링크 열기 | 없음(URL 스킴) | **무료**(사용자 수 무관) |
| 바로가기 → 슬롯 PSR 이름·PID 조회 | 없음(내부 DB) | **무료** |
| 바로가기 → 왕복 실소요시간(Routes API) | Google Routes API 1콜 | **유료 = 클릭당 $0.01** |

- `routingPreference: TRAFFIC_AWARE` = Routes Compute Routes **Pro SKU = $10/1000콜 = 클릭당 $0.01(≈14원)**.
- ⚠️ $200 월 무료크레딧 정책 폐지 = 구글 2025-03 개편(SKU별 소량 무료한도로 대체). 클릭 수만큼 실청구 가능.
- **비용 조절(사장님 선택 = 항목13)**: A(현행 TRAFFIC_AWARE $0.01) / B(TRAFFIC_AWARE 제거 = Essentials $0.005) / C(Routes 제거 = 완전 무료, 딥링크·이름은 유지, 실소요시간만 삭제).

## 7. 동선 시뮬 실측 (우리 순서 vs 구글 최적화, 12콜=$0.06, raw=docs/raw/runtime/)

| 여정 | 우리 순서(하루평균) | 구글 최적화 | 판독 |
|---|---|---|---|
| DB-only (Held-Karp) | 구글 대비 6~12% | 준수 | 알고리즘 양호 |
| MIX (Gemini 순서) | 20~50% 열세 + 좌표불량(26시간) | — | Gemini 동선 개선 필요(별도 과제 §3-14) |

**결론**: 순서는 클릭 시점 화면 그대로(재정렬 안 함=사장님 SSOT). Routes API 실소요시간은 "그날 정말 갈 수 있나" 사후 검증·이상경고(6시간 초과) 역할.
