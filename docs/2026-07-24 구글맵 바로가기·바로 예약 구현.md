## 3. 비용 = 바로가기 클릭 시 Routes API 1콜만 유료

| 동작 | 외부호출 | 비용 |
|---|---|---|
| 바로 예약하기(전문가 문의함 통합) | 없음(내부 DB) | **무료** |
| 바로가기 → 구글맵 딥링크 열기 | 없음(URL 스킴) | **무료**(사용자 수 무관) |
| 바로가기 → PSR 이름·PID 조회 | 없음(내부 DB) | **무료** |
| 바로가기 → 실소요시간·거리(Routes API) | Google Routes API 1콜 | **유료 = 클릭당 $0.01** |

- 우리 코드 `routingPreference: TRAFFIC_AWARE` = **Routes Compute Routes Pro SKU = $10/1000콜 = 클릭당 $0.01(≈14원)**.
- ⚠️ **$200 월 무료크레딧 정책은 폐지됨**(구글 2025-03 개편 → SKU별 소량 무료한도로 대체). 즉 바로가기 클릭 수만큼 실청구 가능(정정).
- **비용 조절 옵션(사장님 선택 = 항목13)**:
  - **A(현행)**: TRAFFIC_AWARE 실시간 교통 = $0.01/클릭.
  - **B**: TRAFFIC_AWARE 제거 → Essentials $0.005/클릭(교통 미반영, 실소요시간은 나옴).
  - **C**: Routes API 제거 → **완전 무료**. 한국어명+PID 딥링크는 유지(PSR 무료), "실소요시간·이상경고"만 삭제.

## 6. 딥링크 장소명 정책 (사장님 실클릭 피드백 반영)

- **문제**: 좌표만 넘기면 구글이 근처 **주소**를 라벨로 표기("62 Rue de l'Hôtel de Ville") = 초행자가 모름.
- **원인(실증)**: DB-only 여정은 슬롯에 PID 미탑재 → 좌표만 전송. PSR(백엔드)엔 전 슬롯 PID+이름 존재.
- **해결(실증)**: 바로가기 클릭 시 day-live가 PSR 조회 → PID+이름 보충 → 딥링크에 반영. i106 Day1 = 9/9 보충, 주소 완전 제거, 순서 1~9 유지.
- **라벨 언어 = 구글 통제(핵심)**: place_id 있으면 구글이 **우리 텍스트를 무시**하고 공식명을 **기기 언어**로 표시(로컬명·한국어명 무엇을 보내도 동일, hl=ko 무관). 한국어 폰 = 유명지(바스티유 광장·노트르담 대성당·팡테옹) 한국어, 나머지(Loulou·Shakespeare) 로컬/영어. = 사장님 방향("PID 상호명 통일") 그대로.
- **폴백 텍스트 = nameLocal(로컬명)**: place_id 실패 시에만 쓰임. 한국어명은 오매칭 재앙(실증: "모베르 시장"→콜마르 450km 밖) = 로컬명으로 안전화. **place_id 유지가 정확도 필수.**
- **사용자 검색**: 딥링크는 place_id로 지점이 이미 경로에 박혀 열림 = 검색 불필요([시작]만). 직접 검색은 구글맵 자체가 기기 언어 지원.
