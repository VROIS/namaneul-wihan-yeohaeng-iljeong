## 4-1. 인증 = 소셜 3종만 신규 가입. 이메일창은 "이미 있는 내 계정 찾기"

```

| 해설 — 개인 촬영 | `place_id` **NULL** | **6개월 뒤 삭제** + R2 사진 삭제 |

```

정리 함수 1벌 = `server/services/account-cleanup.ts`. 부르는 곳 2군데(스케줄러 · `POST /api/admin/account-cleanup`).

> `server/city-place-routes.ts:384` → `itineraryGenerator.generate()` 의 결과는 `res.json(itinerary)`(:412) **응답으로만** 나간다.
> 어디에도 저장하지 않으므로, 앱이 떠나 있으면 **30초와 유료 외부호출 비용이 통째로 증발**한다.
> = 서버가 멈추는 게 문제가 아니라, **서버가 다 해놓고 버리는 게** 문제다.

**정답은 이미 앱 안에 있다 = 영상 생성 방식**(§16 재발명 금지)

| 단계 | 영상 (`server/video-routes.ts`) | 여정 (지금) |
|---|---|---|
| 시작 | 잔액 **확인만**, DB 에 `status:'processing'` 기록 (:169) | — |
| 응답 | **즉시 202** (:177) | 다 만든 뒤 결과 통째로 (:412) |
| 작업 | `void (async () => {...})` 백그라운드 (:188) | 응답 **안에서** |
| 진행률 | 씬마다 DB 갱신 (:314) | 없음(가짜 문구 4개) |
| 완료 | `status:'succeeded'` + URL 저장 (:344) | 저장 안 함 |
| 조회 | `GET` 으로 상태 폴링 (:427) | 없음 |
| 차감 | **성공 시점**(:160, 런던 121 사고 교훈) | 시작 전 `chargeFeature`(:380) |

**이식할 때 이미 정해져 있는 것들 (조사 완료)**

- `itineraries.status` 컬럼이 **이미 있다**(`shared/schema/itineraries.ts:50`, 기본 `'draft'`). 새 컬럼 없이 `'generating'` 값을 쓸 수 있다 → **DB 스키마 변경 불필요**.
- BTS "같이 떠나요"(pinnedPlaceIds)는 **DB-only 직행 = 무과금**(`city-place-routes.ts:375-382`). 이 경로는 백그라운드로 보내면 안 된다.
- 프로필 여정 목록은 `status='representative'` 를 대표 판정에 쓴다(`city-place-routes.ts:97~`). **`'generating'` 행이 목록에 새어 나가지 않는지 반드시 확인**해야 한다.

**사장님께 미리 여쭐 2가지**

1. **차감 시점** — 영상처럼 **성공 시점**으로 옮길지. 시작 시 깎으면 실패 때 5크레딧이 증발한다(런던 121 과 같은 구조).
2. **DB-only 는 그대로 둘지** — 1~2초짜리를 백그라운드로 보내면 화면 전환이 한 번 더 생겨 **오히려 느려 보인다**. `MIX 만 백그라운드` 를 권한다.

## 10-C. 여정 로딩 화면 다시 만들기 (FE, B 뒤에)

**현재** = `client/screens/trip-planner/LoadingStep.tsx`

```
[96×96 파란 사각형 + 손으로 만든 네모 링이 돎 + 나침반 아이콘]
        TRIPIS                 ← 24pt 굵게
   실시간 교통 정보 분석 중       ← 14pt, 2초마다 교체
```

| 무엇이 옥에 티인가 | 근거 |
|---|---|
| **문구가 앱 말투가 아님** | `실시간 교통 정보 분석 중` = 명사 나열체. 다른 화면은 `사진 속 이야기를 찾아내고 있어요...` 같은 말투(`GuideStackNavigator.tsx:319`) |
| **진행과 무관한 가짜 진행** | 4문구가 **2초마다 기계적으로** 넘어갈 뿐(`useGenerateItinerary.ts:123`). "교통 정보 분석 중"일 때 교통 분석을 하는 게 아니다 |
| **스피너가 이 앱 것이 아님** | 96×96 **네모** 링. 다른 화면은 전부 `ActivityIndicator`(동그란 기본) |
| **기다림 화면에 상표명** | 여기서만 `TRIPIS` 를 크게 씀 = 초창기 흔적 |

**왜 B 뒤인가** = B 를 하면 이 화면은 **"갇혀서 기다리는 화면"이 아니라 "잠깐 스치는 화면"**이 된다. 성격이 바뀌므로 모양도 그때 정해야 한다.
