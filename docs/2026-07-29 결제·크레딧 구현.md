## 4. 충전 확정 방식 = 왜 내손앱과 다른가 (TWA ↔ RN)

내손앱은 **TWA = 앱이 곧 브라우저**라, 결제 후 되돌아온 페이지의 JS 가 쿠키로 서버를 불러 충전을 확정합니다. **정상 작동합니다.**

Tripis 는 **RN = 앱이 브라우저가 아님**. 그래서:

| | 내손앱(TWA) | Tripis(RN) |
|---|---|---|
| Stripe 창 | 앱 안 | 앱 **밖** 브라우저 |
| 복귀 페이지 | 앱이 받음 → JS 실행 | 앱이 **못 봄** |
| 인증 | 쿠키 | Bearer 토큰(외부 브라우저는 모름) |
| 확정을 부를 주체 | 그 페이지 JS | **없음** |

→ **"내손앱이 잘못돼서"가 아니라 "RN 에서는 부를 주체가 없어서"** 서버↔서버 직접 통보(웹훅)로 갑니다.
딥링크로 되돌리는 방법은 **2026-07-27 사장님이 실기기에서 겪고 삭제한 함정**(안드로이드 창이 백그라운드에 남고 닫는 기능 없음, `auth-kakao.ts:86-91`)이라 쓰지 않습니다.

**결과**: 창을 닫아도·폰이 꺼져도 충전은 진행됩니다. 앱은 잔액만 다시 조회합니다.

## 12. 【2026-07-31】 "여정 생성 오류" = 배선 아니라 **크레딧 부족**이었다

### 무슨 일

사장님이 폰(아이폰·안드로이드 둘 다)에서 BTS → 메인앱 창 → **여정 생성 시 오류**.
사장님 의심: *"뭔가 배선을 건드린듯"* — 그럴 만했다. 바로 전에 BTS 오버레이 작업을 했으니까.

**하지만 배선은 멀쩡했다.** 진짜 원인은 **그 폰이 로그인한 계정에 크레딧이 0** 이었던 것.

### 왜 아무도 몰랐나 = 화면이 이유를 숨겼다

서버는 **이미 정확히 말해주고 있었다**(실측 응답):

```
402 {"error":"insufficient_credits","message":"크레딧이 부족합니다. (필요: 5, 잔액: 0)","balance":0,"required":5}
```

그런데 화면(`useGenerateItinerary.ts`)이 **어떤 이유든 전부 "다시 시도해 주세요" 한 줄로 뭉갰다.**
= 서버가 준 사실을 **화면이 버렸다.** 그래서 사장님이 원인을 못 찾고 한참 헤매셨다.

> 이건 §10 표에 **이미 예고돼 있던 항목**이다(*"잔액부족(402) 안내가 사용자에게 안 보임 / 차감을 실제로 켜는 순간"*).
> 차감을 켰으니 예정대로 터진 것. **적어만 두고 안 고쳤더니 그대로 왔다.**

### 실측 증거 (DB 읽기 전용 — 쓰기 0)

| 계정 | 크레딧 | 여정 생성 |
|---|---|---|
| `vrois@naver.com` (카카오) = **사장님 폰이 로그인한 계정** | **0** | ❌ 402 |
| `dbstour1@gmail.com` (**관리자**) | 29 | ✅ 됨 (§9 = 관리자 면제) |

### 🔑 "개발본(Expo)에서는 되는데 왜?" — 사장님이 이상하다 하신 것

*"같은 파일 같은 최신 EAS 를 받아서 실행한 것은 됨"* — 맞다. 그리고 그건 **정상**이다.

**Expo Go 는 저장소가 따로다** = 그 안에서는 **로그아웃 상태**였다.
`credit-charge.ts` 는 `userId` 가 없으면 `return true`(= 비로그인 게스트는 안 깎음, 헌법 §9 개발단계 개방).
→ **로그아웃이라 안 깎이고 = 그냥 됨.** 코드 차이가 아니라 **로그인 상태 차이**였다.

### 가입 보너스 140 이 왜 안 들어와 있나 = **정상** (사장님 판단)

> 사장님: *"크레딧 미지급은 버그가 아니라 정상인듯하다. 이유 = 신규가 아니라, 크레딧 지급 로직 붙이기 전에 수없이 테스트했으니 신규가 아니지"*

맞다. 보너스는 **계정을 새로 만드는 순간 1회**만 준다(`auth-user.ts` 의 `createUser` 직후).
그 계정은 **그 로직이 붙기 전에** 만들어졌으므로 받을 기회가 없었다. = 결함 아님.

### 고친 것 = **오직 오류 메시지 1개** (사장님 지시 범위)

> 사장님: *"화면이 '크레딧이 부족합니다' 라고 정확히 보여주게 고침 **이것만 해라**"*

`client/screens/trip-planner/hooks/useGenerateItinerary.ts` — 서버가 함께 보낸 숫자를 그대로 옮겨 보여준다.

```

```

**차감 로직·단가·보너스는 한 줄도 안 건드렸다**(사장님 *"보너스 지급 크레딧은 아직 미정이니 남겨 놓고"*).
