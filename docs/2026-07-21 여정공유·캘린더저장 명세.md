  - `/api` 하위인 이유 = SPA 폴백(`app.get("*")`)이 `/api`만 통과 = `/shared/...` 경로면 index.html이 먹어버림.
- **Android(삼성 포함)·웹** = 구글캘린더 render 링크(`buildGoogleCalendarUrl`, 전체기간 종일 이벤트 1개 + details 일자별 일정) → 구글캘린더 앱/웹 편집화면 → 저장 = 원탭. id 불필요.
- **공유 PC웹 보강** = PC는 navigator.share(빈약한 OS창) 대신 클립보드 복사 + `trip.shareLinkCopied` 안내(7개 locale 추가). 모바일웹은 종전대로 시스템 공유시트.
- **실측(로컬)**: 여정 91 → ICS 12 VEVENT·CRLF·한글 폴딩 정상 / HTTP 200 + text/calendar + UTF-8 filename / 없는 id 404. §22 기계 4종 통과(tsc 160≤161·서버빌드·웹빌드·lint 0).
- **남은 실증** = push+Republish 후 §21: 웹 DevTools(구글링크 열림·복사 안내) + 사장님 실기기(iOS Safari "일정 추가", AOS 구글캘린더 열림).
