## 1. 프로젝트 배경

### 1-1. 왜 만드는가

| 문제 | 해결 |
|------|------|
| WebView 앱 2주간 Android 해결 불가 | React Native 네이티브 전환 |
| nubi(여정생성)와 가이드(AI해설)가 별개 앱 | 하나의 통합 앱 |
| 여행 "전" 계획만 가능 | 여행 "전+중+후" 전 과정 |
| 기계적 설문 폼 UI | 게임식 비주얼 스토리텔링 |
| 오프라인 미지원 | Gemini Nano + 여정 다운로드 |
| 가이드 모집 접점 없음 | ✨🛡️ 현지인 인증 = 비즈니스 핵심 |

### 1-3. 5대 원칙 (모든 설계의 기준)

1. **비주얼 퍼스트** — 텍스트/형식적 요소 NO. 인스타/틱톡 느낌. 직관적 UX만.
2. **라이브 올인** — 촬영/음성 버튼 NO. **Gemini Live가 메인**. 오프라인 포함.
3. **가족 감동** — 연령대별 캐릭터가 여행지에 등장. 가족이 함께 떠나는 느낌.
4. **디자인 일관성** — Gemini 아이콘 색감 기반 디자인 시스템. 전 페이지 일관.
5. **React Native 베스트** — 최고 수준 애니메이션 + 인터랙션.
6. **완전 인앱** — 외부 브라우저/iframe/오버레이 절대 금지. 모든 화면 = React Navigation 네이티브 스크린. (WebView 시절 OAuth 복귀 실패, iframe 리다이렉트 등 반복된 문제 원천 차단)
7. **컴포넌트화 철저** — 정형화된 콘텐츠 = 재사용 컴포넌트 블록. Vercel React 베스트 패턴 활용. 불필요한 코드 삭제, 경량화.
8. **앱 중심** — 웹 버전 아님. 관리자 대시보드만 SvelteKit 웹. 공유페이지도 Svelte 경량.
9. **Apple 수준 디자인** — 이모지 절대 금지. SF Symbols / Lucide 아이콘만. 카드 테두리, 여백, 그림자 전부 Apple HIG 기준. 깔끔하고 절제된 프리미엄 느낌.
10. **디자인 서브에이전트 필수** — 모든 UI 작업 시 `frontend-design` + `web-design-guidelines` + `vercel-react-best-practices` + `design-md` 스킬 동원. Stitch 시안 → `enhance-prompt` → `react-components` 파이프라인 필수.

### Supabase DB 현황 (2026-03-26 직접 조회)
```
전체: 222MB / 500MB (44%)
정리 대상:
  weather_forecast  47MB (43만 행) → TRUNCATE
  weather_cache      6MB (7만 행) → TRUNCATE
정리 후: ~169MB / 500MB (34%) — 여유 331MB

핵심 데이터:
  places           1,772건 (16MB)
  place_seed_raw   6,896건 (23MB) ← SSoT
  place_images    53,752건 (33MB)
  reviews          9,135건 (6MB)
  cities             108건
  users               27건
  guide_prices          9건 ← 실제 가이드 가격표
```

### 4-4. 숏폼 미리보기 — 핵심 차별화 (v1.1 추가, 2026-03-27)

> **최우선 원칙: 가족 감동. 텍스트 여정표는 직관적이지 않고 후킹이 약하다.**
> **캐릭터가 1인칭 대사로 여행지를 소개하는 숏폼이 메인 산출물.**

**기술: Rive 실시간 렌더링 (영상 "생성" 아님 → 대기 시간 0초)**
```
[Rive 엔진 — GPU 실시간 120fps]
  실제 장소 사진 (배경, Ken Burns 줌인/패럴랙스)
  + Rive 캐릭터 애니메이션 (걷기/앉기/먹기/감탄)
  + TTS 1인칭 대사 (사전 캐시)
  + 스와이프 전환
  = 즉시 재생, 생성 대기 0초
```

**검증된 사례:**
- Duolingo: Rive 캐릭터 120fps, 파일 1MB 미만, AI 영상통화까지 구현
- Spotify Wrapped: Rive 인터랙티브 스토리, "역대 최고 구독자 유입일"
- Headspace: 일러스트 캐릭터 + 실사 배경 + 오디오
