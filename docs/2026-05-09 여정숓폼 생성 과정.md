```
AG0 (Promo Video Generator) ★ 신규
  역할 = 시네마틱 숏폼 영상 생성 (= 5 초 안)
  입력 = formData (= 도시 + 일정 + 동행 + vibe + 캐릭터 매칭)
  처리:
    1. DB SELECT (= 0.1 초)
       - place_seed_raw.image_url 8 곳 (= Storage)
       - 14 캐릭터 PNG (= 연령 + 성별 매칭)
    2. Remotion 컴포넌트 빌드 (= ~1 초)
       - TransitionSeries + fade/slide 전환
       - Sequence 8 × 0.5 초 = 4 초 영상
       - Ken Burns 효과 (= 이미지 줌/패닝)
       - 텍스트 모션 (= 페이드인 + 스케일)
       - 캐릭터 PNG 오버레이 (= 우측 하단)
    3. Remotion CLI 렌더 (= 2~3 초)
       - mp4 출력 = public/preview/{itineraryId}.mp4
    4. Web TTS = 브라우저 SpeechSynthesis API
       - 한국어 나레이션 (= 외부 호출 X)
  출력 = mp4 URL
  비용 = $0 (= Remotion 오픈소스 + DB + Web TTS)
  시간 = ~5 초

AG1 (Skeleton)
  역할 = 입력 분석 + 분기 결정 + 슬롯 계산 + 마진
  출력 = skeleton {
    formData, vibeWeights, daySlotsConfig,
    sourceMode: 'db-only' | 'gemini-fallback' | 'mixed',  ← 분기
    cityId, requiredPlaceCount,
  }
  시간 = ~0.5 초

AG2 (Recommender)
  역할 = sourceMode 별 데이터 소스 선택
    - 'db-only' → fetchFromPlaceSeedRaw (= 외부 호출 0)
    - 'mixed' / 'gemini-fallback' → Gemini API + 자체 프롬프트
  출력 = PlaceResult[] (= name + nameKo + nameLocal + address + summary_ko + estimatedCostEur)
  시간 = ~10 초

AG3 (Matcher + Saver)
  역할 = name + address 매칭 + DB 보강 + auto-learn 저장
  - matchPlacesWithDB = name → address 정규식 매칭 (= 정규식 보강 = coulée/jardin/parc 등)
  - saveNewPlacesToDB = searchText (7 필드) + PhotoMedia binary + Storage upload + INSERT
    - 어제 21 식당 패턴 그대로 (= setTimeout 폐기 = 즉시 await)
  출력 = matched PlaceResult[] (= image, lat/lng, place_id 채움)
  시간 = ~1~2 초

AG4 (Finalizer)
  역할 = 슬롯 분배 + 동선 + 비용 + 카드 빌드
  - sourceMode 별 정렬 (= db-only=dbRank ASC / mixed=Gemini 응답 순서)
  - 식당 mealPrice = MEAL_BUDGET[travelStyle] 자동
  - 명소 estimatedPriceEur = editorial_summary "Max €N/person" prefix 추출
  - Routes API 동선 + transit 비용
  - 일일 합계 (= 식당 + 명소 + 교통)
  출력 = 최종 result {days, totalCost, ...}
  시간 = ~3 초

= 총 0~15 초 백엔드 + 0~5 초 영상 = 병렬
```
