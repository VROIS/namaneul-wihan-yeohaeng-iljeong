# 디자인 시스템: BTS WORLD TOUR 'ARIRANG' 여행 컴패니언 앱

> **공식 투어명:** BTS WORLD TOUR 'ARIRANG'
> **앨범:** 정규 5집 "ARIRANG" (2026.03.20)
> **소속사:** 빅히트 뮤직 (HYBE)
> **이중 테마:** BTS 미니앱 = 아리랑 레드 + 보라해 / 범용 앱 = 제미나이 4색 (6단계)
> **이 문서는 BTS 미니앱 MVP 기준**

## 1. 시각 테마 및 분위기

### 1-1. 컨셉 방향: "한국 유산과 글로벌 무대의 만남"

> "아리랑 — 감정, 회복력, 그리고 하나됨의 영원한 상징"
> "한국 유산과 글로벌 무대 에너지의 강력한 융합"

**미학 방향: "신성한 모던(Sacred Modern)"** — 전통 한국 미학의 절제된 아름다움(백자, 단청, 태극)과
현대 콘서트의 몰입적 에너지가 공존하는 디자인. 누가 봐도 **"이건 BTS 아리랑 투어 관련이다"**라고
즉시 인지할 수 있는 강한 아이덴티티.

**핵심 비주얼 DNA (공식 브랜딩에서 추출):**
- **3개의 원형 엠블럼** — 아리랑(ㅇㄹㄹ)의 한글 초성을 원형으로 추상화
  - 첫째 원: 속이 찬 원 + 내부 점 (ㅇ)
  - 둘째 원: 수평 두 줄로 분할 (ㄹ) → 태극기 괘(卦) 연상
  - 셋째 원: 수평+수직으로 분할된 격자 (ㄹ) → 태극기 괘 연상
- **시그니처 레드 온 화이트** — 공식 포스터 기본 팔레트
- **태극기 연결** — 원 내부의 수평선이 건곤감리(乾坤坎離) 연상
- **정국 스케치 기반 로고** — 멤버가 직접 디자인에 참여

**잊을 수 없는 차별점:**
- 앱을 열면 3개의 아리랑 엠블럼이 순차적으로 빛나며 등장
- 전통 한국 문양이 은은하게 배경 텍스처로 흐름
- 시그니처 레드가 보라해 퍼플과 만나 BTS만의 색감 형성
- 360도 스테이지 컨셉이 UI 전체에 "원형" 모티프로 반복

### 1-2. 톤 & 무드

| 키워드 | 설명 |
|--------|------|
| **신성함** | 아리랑의 문화적 무게감, 경건하면서 따뜻한 |
| **영화적** | 콘서트 입장 직전의 설렘, 극장 같은 몰입감 |
| **유산+현대** | 전통 문양 + 현대 글래스모피즘의 대비 |
| **프리미엄** | 애플 HIG 기준 절제, MZ세대가 스크린샷 찍을 수준 |
| **통일감** | 34개 도시가 하나의 시각 언어로 연결됨 |

### 1-3. 디자인 금지사항

- 이모지 절대 금지 (UI 전체)
- 일반적인 AI 폰트 금지 (Inter, Roboto, Arial)
- 과한 그래디언트 (배경 전체 X)
- 보라색만의 앱 (보라해는 포인트, 아리랑 레드가 주역)
- 외부 브라우저/오버레이
- 두꺼운 테두리 (2px 이상)
- 급격한 화면 전환 (스프링 애니메이션만)

## 4. 아리랑 비주얼 시스템 (핵심 차별화)

### 4-1. 3개 엠블럼 (아리랑 ㅇㄹㄹ)

앱 전체에 반복되는 원형 모티프. 공식 로고의 3원을 변주:

```
◉  ☰  ⊞
ㅇ  ㄹ   ㄹ
```

**활용 방식:**
- **로딩 애니메이션**: 3원이 순차적으로 붉게 빛남 (0.3초 간격)
- **섹션 구분선**: 3원이 수평 정렬, `opacity(0.15)` 배경 장식
- **멤버 프로필 링**: 선택된 멤버 = 3원 중 하나의 변주 테두리
- **도시 카드 뱃지**: 아시아=첫째원, 미주=둘째원, 유럽=셋째원
- **탭 표시기**: 활성 탭 아래 점 대신 미니 엠블럼

### 4-2. 전통 문양 텍스처 (은은하게)

| 요소 | 적용 위치 | 강도 |
|------|----------|------|
| 당초문(蔓草紋) | 히어로 배경 오버레이 | `opacity(0.03)` |
| 태극 곡선 | 로딩 스피너 경로 | 선 하나만 |
| 괘(卦) 패턴 | 카드 호버 시 테두리 | `opacity(0.1)` |
| 한지 질감 | 밝은모드 배경 노이즈 | `opacity(0.02)` |

> "은은하게" = 의식하면 보이지만, 의식 안 하면 "그냥 고급스럽다" 느낌

### 4-3. 공연→도시 비주얼 연결

**도시 카드를 보면 즉시 "BTS 아리랑 투어 도시"라고 인지:**

```
┌─────────────────────────────┐
│  ◉ 고양 GOYANG               │ ← 아리랑 엠블럼 + 도시명
│  고양종합운동장               │
│  4/9, 11, 12  ·  3회 공연    │ ← 아리랑 레드 날짜
│  ━━━━━━━━━━━━━━━━━━━━━━━━━  │ ← 아리랑 레드 진행률 바
│  ┌─────┐ ┌─────┐ ┌─────┐   │
│  │ 장소1│ │ 장소2│ │ 장소3│   │ ← place_seed_raw에서
│  └─────┘ └─────┘ └─────┘   │
│  150개 장소 · 5개 카테고리    │
│  [여정 만들기]               │ ← 아리랑 레드 버튼
└─────────────────────────────┘
```

## 7. 애니메이션 및 모션

### 7-1. 원칙

- **스프링 우선**: 감쇠 15~20, 강성 150~200
- **지속 시간**: 200~400ms
- **터치 피드백**: `scale(0.97)` + `opacity(0.8)`, 즉시 반응

### 7-2. 시그니처 애니메이션

| 요소 | 애니메이션 |
|------|-----------|
| **앱 로딩** | 3 아리랑 엠블럼 순차 점등 (레드 글로우, 0.3초 간격) |
| **도시 선택** | 세계지도 줌인 + 엠블럼 핀 펄스 |
| **멤버 등장** | 크기 0→1 + 페이드, 스프링, 순차 딜레이 100ms |
| **숏폼 전환** | 세로 스냅 스와이프, 관성 기반 |
| **카드 호버** | 들어올림 + 그림자 + 괘 테두리 페이드인 |
| **FAB** | 은은한 펄스 2초 주기 (보라해 퍼플 글로우) |
| **화면 전환** | 공유 요소 전환 (카드 사진 → 상세) |
| **탭 전환** | 교차 페이드 200ms |

### 7-3. Rive 캐릭터

```
BTS 캐릭터 7명 x 상태 머신
상태: 대기 → 걷기 → 먹기 → 가리키기 → 감탄 → 앉기
트리거: character.setState('walking')
GPU: 120fps
크기: ~100KB/캐릭터
스타일: 저작권 안전 아키타입 (공식 초상 사용 안 함)
```

## 8. 아이콘
