# NUBI BTS Event Page - Phase 1 결산 (뼈대 확정)

## 🎯 현재 달성한 상태 (승인 완료된 컨셉)
- **앱의 핵심(Core) 인터랙션 100% 확정**: "Focus & Expand" (원형 탭 -> 확대 -> 8장 카드 전개)
- **우주쇼, 다크모드, 쓸데없는 인트로 등 요소 전면 완전 폐기**
- **모바일 네이티브 감각 뼈대 구축**: React Native (Expo) `bts-app` 환경 세팅 완료 (`App.tsx` 단일 파일로 작성 완료)
- **페이지 흐름 (3-Page Flow)**
  1. **Select & Cart Screen**: 7명의 캐릭터 중 하나를 택하면 바이브 카드 8장이 동글게 펼쳐짐 + 카드를 탭하여 장바구니(하단 게이지 바)에 수집하는 로직. 2개 이상 모으면 버튼 팝업.
  2. **Loading Screen**: 선택한 바이브 데이터를 들고 가는 Gemini AI 로딩 애니메이션.
  3. **Dashboard Screen**: 수집한 바이브 종류(예: 📸핫플, 🛍️쇼핑)를 그대로 이어받아, 정확히 일치하는 개수와 맞춤형 스마트 동선 타임라인 카드가 "동적으로" 생성되는 결과 페이지.
