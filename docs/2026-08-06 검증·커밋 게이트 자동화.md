# 검증·커밋 게이트 자동화 — 계획·작업일지·해결책 (정본·백서)

> 2026-08-06 사장님 확정 지시로 구축. **이 파일이 정본(SSOT)** — 추후 커밋 게이트·검증 절차 문제 시 이 파일부터 볼 것.
> 배경 사고 2건(같은 날 사장님 적발): ①승인 스탬프 장치가 7-25 훅 이사 때 유실돼 12일 무방비 ②AI가 검증 절차(판단3종·실증)를 관성으로 건너뜀 + 기계검증은 반대로 4회씩 중복 실행.

## 1. 계획 = 사장님 확정 작업 순서 (이대로 기계가 강제)

```
수정 → 기계검증(4) → 크롬DEV 실증(사용자 관점) → 무한루프(미비 시 재수정)
    → 판단3종 → 표 제시 → 관련 문서 업뎁 → 대기
    → 커밋 승인(스탬프) → 빌드필요 체크 → 최종 커밋·푸시
```

- 표 양식 = **문제점·해결책·사용자 관점 개선 효과** 포함.
- 문서 = 항상 **그 작업의 지정 정본 문서**에 업뎁(워크로그·메모리 요약이 아님) = 정본이 계획→작업일지→해결책의 완결 백서.

## 2. 해결책 = 만든 것 (문제점 → 해결 → 효과)

| 문제점 | 해결책 (구현) | 사용자(사장님) 관점 개선 효과 |
|---|---|---|
| 기계검증(tsc·서버빌드·웹빌드·lint)이 수정 중·훅·사후 등 **4회씩 중복** = 시간·비용 낭비 | 통과 시 **코드 지문 마커** 기록(`.verify-state.json`) → 커밋 훅은 재실행 대신 지문 대조. 코드가 안 바뀌면 생략, 바뀌면 그 단계만 재요구 | 같은 검증을 두 번 안 봄 = 커밋이 몇 분 → 몇 초. 검증 생략은 불가능(지문이 다르면 자동 재실행) |
| 판단3종·크롬 실증이 **글로만 있어** AI 관성이 건너뜀 | 코드 커밋인데 실증·판단 마커 없음/낡음 = **커밋 물리 차단**(문서 전용 커밋만 면제) | "실증 안 하고 소설" 원천 차단 — 기계가 막음 |
| 승인 스탬프 유실(7-25) = 지시 없는 커밋 가능 | `guard-commit-approval.mjs` 복원(1회용·5분) + **훅 맨 앞** 배치(헛검증·검증 중 만료 함정 제거) + post-commit 자동 소멸 | "커밋해" 명시 문구 없이는 커밋 자체가 안 됨 |
| 빌드필요 판단을 잊음 | 커밋 직전 `needs-rebuild.mjs` 자동 표시(정보) | 커밋 때마다 "앱 다시 구워야 하나"가 자동으로 보임 |

**사용 도구 1벌** = `scripts/verify-pipeline.mjs` (기존 검증기 전부 재사용, 재발명 0):

| 명령 | 언제 |
|---|---|
| `node scripts/verify-pipeline.mjs machine` | 수정 후 = 가드3+기계4 실행·마커 기록 |
| `... evidence "근거 1줄"` | 크롬DEV/실호출 실증 완료 직후 |
| `... judge-pass` | 판단3종(verify-workflow) allPassed 후에만 |
| `... status` | 현재 어디까지 왔나 표(사장님 확인용) |
| (자동) `hook-check` | pre-commit이 호출 = 토큰 → 가드3 상시 → 지문 대조 → 빌드필요 표시 |

**솔직 한계**: 마커·스탬프 모두 AI가 허위 호출 가능(파일·훅을 만지는 존재라 완전 차단 불가). 실효 = 무심결·관성 생략의 기계 차단 + 시각·지문 감사 흔적. 운영 규칙 = stamp/judge-pass는 각각 사장님 승인·판단 통과가 있는 그 턴에서만.

## 3. 작업일지 = 무한루프가 실제로 잡은 버그 (판단3종 6차 재검)

| 차수 | 잡은 실버그 | 수정 |
|---|---|---|
| 1차 | (크레딧 수정분) 차감 예외가 완성 영상 기록을 failed로 덮어씀 | 차감 자체 try/catch = succeeded 보존 |
| 2차 | **파이프라인 자체가 .gitignore `scripts/verify-*.mjs`에 걸려 레포 미추적** = 7-25 훅 유실 사고 재생산 위기 | `!scripts/verify-pipeline.mjs`·`!verify-before-commit.mjs` 예외 |
| 3차 | 지문 = diff 텍스트 md5 → 1MB 초과 diff에서 게이트 크래시(커밋 영구 차단) + 코드 경로 나열 누락(plugins/ 등) | git blob 해시 기반 지문 + maxBuffer 64MB + 경로 보강 |
| 4차 | 경로 나열이 또 누락(babel.config 등 루트 설정 파일) = **나열 방식 자체가 결함** | 반전: 문서(docs/·*.md)만 면제, 나머지 전부 코드 취급 |
| 5차 | **한글 파일명**(이 레포 docs 대부분)이 git 따옴표 인용 출력 때문에 코드로 오분류 = 문서 수정마다 마커 무효 | `git -c core.quotepath=false` + 한글 .md로 직접 재실증(지문 불변 확인) |
| 6차 | 차단 0 = 통과 | — |

부수 사고·교훈: 실증 뒷정리 중 `git checkout`으로 미커밋 문서 문단 소실 → 즉시 재작성 복구. 이후 원복은 **백업 복사 방식**으로 통일(파괴적 git 명령 금지 재확인). 실증 대상 서버 확인 절차화(옛 프로세스 5000·Metro 8082에 헛호출했던 함정).
