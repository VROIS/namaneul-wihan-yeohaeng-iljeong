> 2026-07-25 착수·완료. 사장님 지시: **"로그인 페이지 불필요 → 인앱 팝업으로. '내손앱'처럼. 생년월일 필수만 추가. 그냥 메인앱만 하라."**

## 1. 배경 (왜) — 표

| 항목 | 내용 |
|---|---|
| 사장님 지시 | 로그인 = 별도 화면 말고 **인앱 팝업**. '내손앱'처럼. 생년월일 필수만 추가. |
| 핵심 요구 | **1회 로그인 → 로그아웃 전까지 유지 → 재접속 시 안 물어봄** ("1회 회원가입이 끝"). |
| **2가지 필수 입력**(2026-07-25 사장님 SSOT) | 로그인 팝업 뜰 때(=비로그인 상태 = 최초 가입 **또는 강제 로그아웃 후**) = **생년월일 + 소셜인증(구글/카톡/이메일 중 1) 둘 다 필수**. 이유: **생년월일이 비밀번호 역할 대체 + 사용자 진짜 생년월일을 다시 유도**. 구글·카톡·이메일 3종 모두 생년월일 게이트(requireBirthDateAndAdult) 통과 필수. |
| **재로그인 시 생년월일** | 로그인 인식되면 팝업 자체가 안 뜸(생년월일 볼 일 없음). 비로그인이면 팝업 뜨고 2가지 필수 = "숨김 로직" 불필요(사장님 "이게 왜 필요?"). |
| 복잡도 방침 | "인증 만드는 과정이 너무 복잡함" → **이미 검증돼 도는 것 그대로 재사용**. 새로 안 만듦. |
| 범위 | **메인앱만.** 곁가지(WhatsApp/BTS/언어선택/애플/64명/신원교체) 제외. |
| 애플 | **별도 세션**(OTA 불가·iOS 새빌드·웹검증불가 = 배포경로 달라 분리). |
| 토큰 | 지금 것(`simple_auth_token_v1_`) 그대로. 진짜 JWT 교체 = 이번 아님. |
| **라이브러리 방침**(2026-07-25 조사 후 확정) | **새 인증 라이브러리 안 깜.** react-native-app-auth(Expo 폐기·카카오/이메일 안됨·UI없음)·Clerk(카카오 내장안됨·월구독·크레딧 주도권 넘어감) 둘 다 조사 결과 부적합. **이미 깔린 expo-auth-session(구글)+@react-native-kakao(카카오 공식)+자체 이메일이 최적**. |
| **구글 웹 400** | 유일한 실제 문제. 코드 아니라 **Google Console 웹 리다이렉트 URI 미등록**(사장님만 가능). |
| **팝업 디자인** | **지금 로그인 화면 그대로(글라스 미니멀)** = Tripis 로고+생년월일+카카오/구글 버튼. 새 디자인 안 만듦. |
| **로고+문구 리사이즈**(사장님 강조=앱 정체성) | **방법 B = 팝업 크기 따라 실시간 리사이즈**. 로고+타이틀 = SnapSheet translateY interpolate로 full=크게/peek=작게. 슬로건 = `adjustsFontSizeToFit numberOfLines={2}`로 자동축소(성능안전 하이브리드). 로고 aspectRatio:1 + min/max clamp(56~120). |

## 2. 조사 확정 사실 (재조사 불필요) — 표

| 사실 | 근거 (파일:라인) | 함의 |
|---|---|---|
| 구글·카카오·이메일·게스트 = **이미 작동 중** | `server/auth.ts` `/api/auth/google·kakao·email-login`, `client/lib/auth.ts` `socialLoginWith*` | 새로 만들 것 0 = 복잡도 0 |
| **인증 지속 = 이미 완성** | `client/lib/auth.ts:49` `saveAuth`(AsyncStorage 영구), `:35` `getUserData`, `:58` `clearAuth` | 앱 재시작·재접속해도 유지 = "1회 로그인=끝" 이미 충족. 새로 안 만듦 |
| 인앱 오버레이 표준 = **SnapSheet** | `client/components/SnapSheet.tsx` (ExpertSheet가 이미 사용) | 팝업 껍데기 재사용. `visible/onClose/title/children` |
| 로그인 로직 = **useLogin 훅에 완성** | `client/screens/login/hooks/useLogin.ts` (생년월일/검증/소셜핸들러/게스트) | 로직 재사용, `navigation.reset("Main")`만 `onDone()`으로 |
| 전역 신호 패턴 존재 | `client/contexts/MapToggleContext.tsx` `requestExpert`/`expertRequestedAt` | 대칭으로 `requestLogin`/`loginRequestedAt` 추가 |
| 로그인 게이트 단일 함수 | `client/screens/trip-planner/hooks/login-gate.ts` `ensureLoggedIn` | `navigate("Login")` → `requestLogin()` |
| 앱 첫 진입 = 바로 메인 | `client/navigation/RootStackNavigator.tsx` `initialRouteName="Main"` | 로그인 강제 없음 = 화면 삭제해도 UX 무리 없음 |
