# 벽돌 3 = 나누기 넣음 + 빡빡하게 (2026-09-10)

줄 세우기(벽돌1) + 유료마감 풀기(벽돌2) 위에 **날별 나누기**를 얹고, 설정은 빡빡하게(Packed 60분).

나누기 = 세운 줄을 날 수만큼 토막낸다. 줄 순서는 안 끊고, 각 토막의 (머묾+이동) 합이 고르게 되는 자리로 자른다.
