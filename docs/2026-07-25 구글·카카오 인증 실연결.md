### ✅ 2. 애플 로그인 = **네이티브**(카톡·구글과 같음)

대신 애플이 공개한 도장(공개열쇠)으로 **우리가 직접 서명을 대조**해야 한다 = `jose` 를 넣은 유일한 이유.
대조 3가지(하나라도 어긋나면 거부) = ①서명이 애플 것인가 ②발급자가 애플인가 ③**우리 앱에게 준 것인가**(`aud`).
③이 없으면 남의 앱 애플 표로 우리 앱에 들어온다 = 구글 `aud`·카카오 `app_id` 대조와 **같은 원칙 1벌**.

## 2. 근본 원인 (내부 코드 + 공식문서 딥리서치 일치)

### 2.1 공통 1차 = 열쇠(EXPO_PUBLIC_*) 운영 미주입 (코드로 확정)

- Expo는 **`EXPO_PUBLIC_` 접두사 값만** 웹/앱 빌드에 인라인 주입.
- **`.env`(운영/git)** = `GOOGLE_CLIENT_ID`·`KAKAO_CLIENT_ID`·`KAKAO_CLIENT_SECRET` (전부 서버용, 접두사 없음) → 클라 빌드 미도달.
- **`.env.local`(로컬 전용, git 제외)** = `EXPO_PUBLIC_GOOGLE_CLIENT_ID`·`EXPO_PUBLIC_KAKAO_JAVASCRIPT_KEY`·`EXPO_PUBLIC_KAKAO_REST_API_KEY` → **로컬만 있고 Replit Secrets엔 없음**.
- 결과: 운영 웹 빌드에 키 빈칸 → `isGoogleOAuthConfigured()`/`isKakaoOAuthConfigured()` = false → `handleGooglePress`/`handleKakaoPress`가 **진짜 OAuth 대신 `handleSocialLogin` 폴백**(providerId 없이) 호출 → 서버 `/api/auth/social-login`이 providerId 필수라 **400**.
  - 근거: `auth-oauth.ts:11,25-27` · `auth-kakao.ts:10-20` · `useLogin.ts:270-277,332-346` · `server/auth.ts:276-280`.
- ⚠️ 이 폴백 분기 자체가 §0/§19 위반(providerId 없이 호출→400 유발 + 진단 흐림) = 삭제 대상.

### 2.2 구글 2차 (1차 고친 뒤 드러날 수 있음)

- `auth-oauth.ts:19-21` = web/ios/android Client ID에 **같은 값 하나** 주입. 웹은 반드시 **"Web application" 타입** Client ID여야 함(iOS/Android 타입 넣으면 authorize 400).
- GCP 콘솔에 **현재 운영 origin(`https://my-guide.replit.app`) 미등록** → `redirect_uri_mismatch`/`invalid_client` 400.
- 서버 `aud/azp === GOOGLE_CLIENT_ID`(`auth.ts:110-111`) = 클라 Web client ID와 안 맞으면 401.
- 플레이스홀더 폴백(`auth-oauth.ts:13-15`, `000000000000-...`) = 키 없으면 더미가 실제로 나가 400.

### 2.3 카카오 2차 = 브라우저 직접 토큰교환 (구조 결함, 키 넣어도 웹 실패)

- `auth-kakao.ts:119-129` `exchangeKakaoCodeForToken` → `issueAccessTokenWithCodeWeb` → **브라우저가 `kauth.kakao.com/oauth/token` 직접 POST**.
- 카카오 공식 규칙: 이 교환은 (1)`client_secret` 필수(기본 ON) (2)**서버에서만** 호출 (3)브라우저 직접호출 = **CORS 차단**. → 브라우저 fetch 실패 → "서버 연결 실패".
- 우리 서버엔 code→token 교환 엔드포인트 **없음**(`/api/auth/kakao`는 accessToken만 받음). → **콜백 엔드포인트 신설 필요.**
- 보안: REST API 키가 `EXPO_PUBLIC_`로 **프론트 노출 중** = 서버 전용으로 이동 필요.

- 안드로이드 = Chrome 모바일 에뮬(360x800x3, UA SM-S918B). WebView 내 구글 OAuth `disallowed_useragent` 별도 확인.
- iOS 실기기 최종확인 = 사장님 몫.

## 7. 리스크

- **WebView(안드 주력) 구글 제약**: 구글은 WebView 내 웹 OAuth를 `disallowed_useragent`로 차단 가능 → 네이티브는 androidClientId+시스템브라우저/커스텀탭. **확인필요.**
- 카카오 네이티브: Android 키해시(디버그/릴리스) 등록 필수(미등록=KOE009). iOS URL Scheme(`kakao{NATIVE_APP_KEY}`).
- iOS Expo Go: 네이티브 SDK 미포함 가능(dev client/EAS 필요) = 크래시 위험. 실기기=사장님.
- OTA: `EXPO_PUBLIC_*`는 빌드타임 인라인 → Secrets 추가 후 **Republish 필수**. 서버 DB api_keys 로더로는 클라 소급주입 불가.
- redirect_uri 완전일치 함정(슬래시·포트·대소문자 하나만 달라도 400/KOE006).
- 레거시 64명(provider_id NULL) = 구글 정식화 시 도달불가 지뢰([[project_legacy_64users_orphan_landmine]]) = 로그인 정식화 시점 백필.
