# Screen C 레이아웃 규칙 (사용자 시안 기준 확정)

## 핵심 규칙
1. **텍스트 "누구랑 여행하고 싶으세요?"가 정중앙**
2. **7명 캐릭터가 텍스트를 둘러싸는 배치** (텍스트 아래가 아님)
3. **캐릭터는 선명하고 즉시 인식 가능** (흐릿함 금지)
4. **배경은 깨끗하고 프리미엄** 

## 시안 참조
- 파일: persona_selection_entry.png (사용자 제공 원본 시안)
- 밝은 배경, 미니멀
- 캐릭터 아바타 크고 선명
- 텍스트가 원형 배치의 중심

## 시네마틱 연출 결과
- 다크 배경 + 스포트라이트 시도 → 캐릭터가 흐려지고 조잡해짐
- 결론: 시네마틱 효과는 이 화면에 적합하지 않을 수 있음
- 사용자 피드백: "연출이 시네마틱하게 안나오는데 뭔가 많이 부족 완성도가"
