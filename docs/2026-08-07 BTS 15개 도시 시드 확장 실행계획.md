## §1. 왜 이 작업을 하는가

- BTS 2026~2027 월드투어 15개 도시 콘서트 확정(사장님 제공 일정표 = 원재료).
- 15개 도시 전부 이미 DB 존재(도시당 68~131행 + bts_venue 좌표) = **기존 도시 보강**(신규 발굴 아님).
- 사장님 일정표 ↔ DB 대조 불일치 발견(여분 날짜 3건 + 시간 6건) → **일정 재검증 1순위**.
- 수량 = 최초 100(60+40) → **도시당 50(6cat×5 + 식당20)으로 축소 확정**. 근거 = 코드 실측:
  BTS 앱 노출 8슬롯(공연장1+바이브5+점심1+저녁1), 후보 조회 = 카테고리당 15·**식당 딱 20**(`server/bts-routes.ts:304`), 옛 이미지 cron = 카테고리당 5·식당 10 운영 전례. 축소 = 비용·시간 약 절반.

## §3. "기존 필시티 방식" 5단계 (쉬운 설명)

| 단계 | 하는 일 | 돈 |
|---|---|---|
| ① 정제(cleanse) | 기존 장소(이름·가격·설명) AI 재확인·교정 | Gemini 1~2콜 |
| ② 발굴(discover) | 6개 테마 각 **상위 5곳** 신규 발굴(Gemini 1콜 + TS 6콜) | 나감 |
| ③ 식당발굴(restaurant) | 도심+외곽(기존 그대로) + **공연장 50km 인기순 20곳(신규 1콜)** | 나감 |
| ④ 결손보강(repair/#45) | **이번 대상(TOP5×6+식당20)만** 빈칸 채움 + **비구글 이미지 → 구글이미지 교체**. **곳당 €0.5**(TS+PM+세금, 사장님 실청구액 = §9) = **가장 비쌈** | 최대 |
| ⑤ 검증(verify) | DB 리포트 | 무료 |

**④ 이미지 정책 = 코드가 이미 사장님 방침대로**: `fillcity/repair.ts:122` = 이미지 URL이 구글출처(`place-images`)가 아니면 "결손" 판정 → 위키/언스플래시 이미지 자동으로 구글 PM 이미지 교체. **범위(TOP5+식당20)만 인자로 좁힘**(§7 변경4).

## §6. 에이전트 역할·정확 명령

### 에이전트 A — 일정·공연장 재검증 (1순위)

- 도구: `fillcity/steps/bts-schedule-verify.ts`(§7 변경3 — cities에 쓰는 기존 도구가 카탈로그 #01~#46에 전무함을 전수 확인 = 불가피한 신규. Gemini는 기존 게이트웨이 재사용).

- **출력 스키마(도구가 Gemini에 강제)**: `{ concert_dates:["YYYY-MM-DD"...], show_times:[{date,time:"HH:MM"}...], time_confirmed:bool, source_tier:"official"|"fan_tracker"|"news"|"unclear", source_urls:[...], conflicts_found:bool, matches_db:bool, notes_ko }`.
- **게이트(결정6) 의사코드**: `if (tier==="official" || (tier==="fan_tracker" && !conflicts_found)) → UPDATE cities SET bts_concert_dates, bts_show_times, bts_time_confirmed, bts_source=source_urls.join(", "), bts_verified=(tier==="official"), updated_at=NOW() WHERE id=N` / 그 외 → `⚠️ 수동검토` 출력만.
- **회귀검증**: LA(124)는 현재 유일한 `bts_time_confirmed=true` = **diff=0이 정상**. LA에서 변경 제안이 나오면 도구를 의심하고 전체 배치 중단 → 보고.
- 산출물: 15개 도시 대조표(옛값 → 새값 → 출처 URL → 자동반영/수동검토).

### 에이전트 B — 장소 발굴 (도시 1개 = 순차 7단계, 도시 간 최대 3병렬)

```
1. npx tsx fillcity/status.ts --city-id=N                                    # 무료 현황
2. npx tsx fillcity/fill-city.ts --city-id=N                                 # 무료 비용 미리보기 (⚠️ --apply 없이!)
3. npx tsx fillcity/fill-city.ts --city-id=N --only=cleanse --apply [LANG]
4. npx tsx fillcity/fill-city.ts --city-id=N --only=discover --top=5 --apply [LANG]
5. npx tsx fillcity/fill-city.ts --city-id=N --only=restaurant --apply [LANG]   # 도심+외곽+venue 1콜(§7 변경5로 배선됨)
6. npx tsx fillcity/repair.ts --city-id=N --top6=5 --rest-top=20 [LANG]         # dry = 대상 수 확인 (무료)
   npx tsx fillcity/repair.ts --city-id=N --top6=5 --rest-top=20 [LANG] --apply
7. npx tsx fillcity/fill-city.ts --city-id=N --only=verify                   # 무료 리포트
```

- 진행: LA(124) 단독 파일럿 → 지역혼합 3개 병렬(중남미1+동남아1+오세아니아1) → 나머지 3개씩.
