## 🔄 백엔드 파이프라인 (구현 완료 = 코드가 정본)

**전 과정 = `POST /api/itineraries/:id/video/generate` body `{day}` 1개 호출로 자동 진행:**

```
[1] 재료 준비 ✅ server/video-routes.ts
    여정 행(rawData.days[day-1].places = 해당일 슬롯 전부, 최대 10) + 사용자 행(users.birth_date)
    + apipass 출입증 발급(issueApiKey, cityId=null 런타임)
        ↓
[2] 스토리보드 = Gemini 1콜 ✅ server/services/ghibli-travel-storyboard.ts::buildGhibliStoryboard()
    ⚠️ 핵심(후임 착각 금지): 스토리보드는 코드 템플릿이 아니라 **Gemini 호출**로 만든다(사장님 확정 = 'AI의견' 패턴).
    - **출연진 동적 구성 = selectGhibliCast()** (사장님 SSOT 2026-07-22 = 옛 "주인공 1명" 폐기):
      · 인원·구성 = 여정 플래너 **'누구랑'(companionType+companionCount)이 정답** = 차량·교통비와 동일 소스
        (혼자=1 / 커플=본인+배우자 / 가족=부부+동반들 / 대가족=부부+부모 / 친구들=동나이대 혼성 N)
      · 나이 = **users.birth_date 실계산**(protagonist-generator calculateAge 재사용 §16, 없으면 40대 가정)
        + 동반 나이 = companionAges 입력 우선("55,59" 등), 없으면 추정(자녀=본인-30, 부모=본인+25 SSOT)
      · 차량 = companionCount 자동(1~4세단·5~8밴·9+버스) / 레퍼런스 이미지 = 일행(최대4)+가이드+차량 = 최대 6장
      · 실증 2026-07-22: 가족4(부부30대+부모 55·59) = 4명 전원 + 가이드가 한 화면에 등장 확인
    - "우리가 가진 것 전부 다 줌"(셀렉 금지): 여정 메타+바이브+슬롯 전요소(PSR summaryKo·editorialSummary·시간·식사여부)
      +출연진·차량 정보를 JSON 통째로 geminiJson()(§16 관문)에 투입
    - Gemini가 하루 전체 씬(슬롯 수만큼, 최대 10)의 {visualPrompt(영어), narrationKo(한국어 대사)}를
      **한 번에** 작성 = 기승전결·대사 일관성·환각 차단. 프롬프트 = buildStoryboardPrompt() (프롬프트=코드 SSOT)
    - 비용 ≈ $0.01 미만, ~3초. raw = saveRaw 2곳 저장(runtime 폴더)
        ↓
[3] 씬 병렬 생성 ✅ server/services/shared/video-gen-client.ts::generateSceneClip() (§16 단일관문)
    씬마다: 프롬프트(sceneClipPrompt = visualPrompt + 한국어 나레이션 오디오 지시)
    + 레퍼런스 이미지 최대 6장(일행들→가이드→차량 순 = <IMAGE_REF_0..N>)
    → gemini-omni-flash-preview Interactions API(reference_to_video, 9:16) → 6초 mp4 클립
    전 씬 동시(Promise.all) = 속도 최우선. 진행률 = video_by_day.scenesDone 갱신. ~40초. §18 메타 saveRaw
        ↓
[4] 결합(편집) ✅ server/services/video-stitcher.ts::stitchAndUpload()
    ffmpeg-static concat -c copy(무재인코딩, ~1초) → 길이 검증(씬수×6초 ±15%)
        ↓
[5] 보관·표시 ✅
    Supabase Storage `itinerary-videos/{여정id}/day{N}.mp4`(x-upsert = 재생성 시 덮어씀 = 여정·일당 1파일)
    → itineraries.video_by_day[day] = {status:'succeeded', url, taskId, scenesDone, totalScenes}
    → 앱은 GET /api/itineraries/:id/video 폴링으로 진행률·완료 URL 수신
```

**안전장치** ✅: 같은 day 생성 중 재요청 = 409(이중지출 차단) / 서버 사망으로 processing 고착 시 = 15분 경과하면 자동 재생성 허용+failed 표시(staleness) / 모든 유료호출 raw 메타 2곳 저장(§18).
