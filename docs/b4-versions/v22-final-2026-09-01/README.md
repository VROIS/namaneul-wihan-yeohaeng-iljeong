## 1-engine-dbonly = 여정 엔진 (DB-only 분기)

확정 규칙 (사장님 SSOT):

1. **카테고리가 바깥 껍질 = 최우선.** 사용자가 고른 바이브 안에서만 뽑는다.
   힐링을 고르면 루브르(heritage ★7)는 안 나온다.
2. **그 안에서 베스트 → rank 순.** 쇼핑을 고르면 갤러리 라파예트(shopping ★7)가 1번.
   = 이 엔진의 핵심 = "그 카테고리 중에서 사람들이 베스트로 꼽는 곳"이 제일 먼저.
3. **카테고리를 다 쓰면 다음 순위로.** 나이로비 힐링 6곳 소진 → heritage 베스트로.
   바이브 3개면 50/30/20 비중, 1순위부터 소진.
4. **점심 = 12:00 을 지나는 활동 "뒤".** 베르사유 13:30 하차 = 그 자리에서.
5. **저녁 = 19:00 이후, 마지막 활동 뒤.**
6. **유료 입장지 = 18:00 이후 시작 불가**(대부분 폐관). 그 뒤는 무료·구경만.
7. **슬롯시간 = 입장료 ÷ 시간당요금**(도시 평균 ÷ 2), 30분 반올림.
   heritage·attraction·adventure·healing 만 대상. €3 이하·무료 = 밀도값.
8. **밀도 = 곳수를 정한다.** 유료 슬롯은 밀도와 무관(설계). 무료는 밀도대로(60/90/120분).
9. **6시간 넘는 슬롯 = 점심 건너뜀**(테마파크 안에서 해결).
10. **본배치·빈틈보충 = 1경로.** 2경로면 날마다 결과가 달라진다.
11. **외곽에서 더 갈 곳이 없으면 도심 귀환** 후 이어 채운다.
12. **같은 이름이 500m 안에 또 있으면 건너뜀**(거리만 보면 78m 떨어진 별개 명소가 잘림).

검증된 결과:
- 파리 3일 Culture = 베스트 13곳 전부 · 중복 0
- 파리 5일 Culture = 베스트 13곳 전부 · 활동 44곳 · 다섯 날 식사 2회
- 릴랙스 3일 Culture = 베스트 13곳 전부(활동 14곳 중 13곳)
- 파리 5일 Healing = healing 40곳 전부, 1번이 튈르리 정원(healing ★1)
- 나이로비 5일 Healing = 힐링 6곳 전부 + heritage 베스트로 이어짐
- 파리 5일 Shopping/Healing/Hotspot = 57%/34%/9%, 각 카테고리 베스트가 앞
