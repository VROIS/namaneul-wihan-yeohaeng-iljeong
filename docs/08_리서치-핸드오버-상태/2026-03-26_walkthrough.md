# Unified ID 및 마스터 DB 구축 최종 보고서

대표님의 지침에 따라 **111R1 방식의 Unified ID**를 구축하고, 흩어진 데이터를 `place_seed_raw` 마스터 테이블로 집결시키는 작업을 완료하였습니다.

## 1. 주요 성과

### ✅ Unified ID (111R1) 체계 확립
- **로직 반영**: `${대륙}${도시순위}${거점}${카테고리}${장소순위}` 형식의 고유 ID 부여 (예: `1011A1`)
- **대상**: 5,250개의 모든 장소 데이터에 누락 없이 ID가 부여되었습니다.

### ✅ 인스타 우선순위 이미지 통합 (Priority 1)
- **우선순위 로직**: `instagram_photos` (좋아요 순) > `celebrity_place_evidence` > `places.photoUrls` 순으로 최적의 이미지를 추출하여 `best_image_url`에 담았습니다.
- **결과**: 현재 DB에 살점(데이터)이 있는 모든 장소에 대해 가장 '핫한' 사진이 마스터 테이블로 집결되었습니다.

### ✅ 데이터 통합 매칭 강화
- **보정 작업**: 이름 정규화(띄어쓰기/특수문자 무시) 및 별칭 매칭을 통해 통합 성공률을 높였습니다.

---

## 2. 현재 상태 및 한계점 (Handover Point)

현재 마스터 데이터 통합 현황은 다음과 같습니다:
- **전체 장소**: 5,250건
- **Unified ID 생성**: 5,250건 (100% 완료 ✅)
- **살점(데이터) 통합**: 약 200여 건 (4%)
    - **원인 분석**: 5,250건 중 3,500건 이상은 아직 구글/인스타에서 정보를 수집하지 않은 '리스트' 상태입니다 (Raw 데이터 창고인 `places` 테이블이 비어 있음).
    - **매칭 성공률**: 현재 `places` 테이블에 존재하는 데이터에 대해서는 **95% 이상 매칭**되어 살점이 입혀졌습니다.

---

## 3. 후임자를 위한 다음 작업 가이드

1.  **미수집 데이터 크롤링**: `place_seed_raw`에는 있으나 `places`에는 없는 약 3,500개의 장소에 대해 구글 맵스 및 인스타 수집 엔진을 가동해야 합니다.
2.  **자동 동기화**: 새로운 데이터가 수집될 때마다 `sync-master-place-seed.ts`가 정기적으로 돌아 마스터 테이블을 업데이트하도록 설정해야 합니다.
3.  **엔진 연결**: 완성된 `place_seed_raw` 파일을 여정 생성 엔진(`itinerary-generator.ts`)의 Main Source로 연결하여 속도를 개선해야 합니다.
