## 4-1. 인증 = 소셜 3종만 신규 가입. 이메일창은 "이미 있는 내 계정 찾기"

```

| 해설 — 개인 촬영 | `place_id` **NULL** | **6개월 뒤 삭제** + R2 사진 삭제 |

```

## 10-A. 앱 첫 실행 = 잠깐 뜨는 빈 화면 (FE, 작음)

**증상** = 앱을 열면 스플래시가 걷힌 뒤 **빈 화면이 한 순간** 스쳤다가 여정 플래너가 뜬다.

**원인** = `client/App.tsx:63-71`

```jsx
useEffect(() => { if (loaded || error) SplashScreen.hideAsync(); }, [loaded, error]);
if (!loaded && !error) return null;        // ← 폰트 10벌 읽는 동안 화면이 null
```

= 스플래시를 걷는 기준이 **"폰트 다 읽음"**이지 **"첫 화면이 그려짐"**이 아니다.

**해야 할 일** = 걷는 기준을 **첫 화면이 실제로 그려진 순간**(루트 View 의 `onLayout`)으로 옮긴다. Expo 공식 패턴이고 줄 수는 몇 줄이다.

**주의** = 폰트 로드 실패(`error`) 때도 반드시 걷어야 한다. 안 그러면 **스플래시에 영구히 갇힌다**.

## 10-B. 여정 생성 = 백그라운드 전환 (백엔드 구조, 큼) — ⚠️ 2026-08-10 시도 후 원복(위 "오늘 작업 기록" 참고)

**사장님 진단** = DB-only(1~2초)는 기다림이 안 느껴지는데, **MIX 는 최대 30초 동안 이 화면에 갇힌다.**
**원하시는 것** = 백그라운드로 돌리고 화면을 나가 다른 일 → 완료되면 여정 화면을 열어줌. **앱을 완전히 껐다 돌아와도.**

**핵심 질문에 대한 답** = *"FE 상관없이 우리 서버가 중단 없이 도는가?"*

> **계산은 끝까지 돈다. 그런데 결과가 버려진다.**
> `server/city-place-routes.ts:384` → `itineraryGenerator.generate()` 의 결과는 `res.json(itinerary)`(:412) **응답으로만** 나간다.
> 어디에도 저장하지 않으므로, 앱이 떠나 있으면 **30초와 유료 외부호출 비용이 통째로 증발**한다.
> = 서버가 멈추는 게 문제가 아니라, **서버가 다 해놓고 버리는 게** 문제다.

**정답은 이미 앱 안에 있다 = 영상 생성 방식**(§16 재발명 금지)

**이식할 때 이미 정해져 있는 것들 (조사 완료, 여전히 유효)**

- `itineraries.status` 컬럼이 **이미 있다**(`shared/schema/itineraries.ts:50`, 기본 `'draft'`). 새 컬럼 없이 `'generating'` 값을 쓸 수 있다 → **DB 스키마 변경 불필요**.

- 프로필 여정 목록은 `status='representative'` 를 대표 판정에 쓴다(`city-place-routes.ts:97~`). **`'generating'` 행이 목록에 새어 나가지 않는지 반드시 확인**해야 한다.

**사장님께 미리 여쭐 2가지**

## 12-5. ⚠️ 지도 배경 지명 = 알려진 한계(배포 후 실기기 재검증 필요)

**증상**: 구글 지도 SDK는 **그 페이지가 처음 로드되는 순간의 언어로 고정**되고, 이후 앱 안에서 언어를 바꿔도(재접속 없이) 이미 뜬 지도는 안 바뀜(구글 SDK 자체 설계 = 코드로 우회 불가, 캐시 문제 아님). 로컬 실증에서 실제 로드된 스크립트가 `intl/zh_ALL`(중국어 고정)인데 그 뒤 화면은 영어→스페인어→불어로 다 바뀌어도 지도만 중국어 그대로였음(직접 확인).

**사장님 확정 기준**: "언어설정 시 그 언어로 지도 고정, 접속 중엔 유지, 언어설정 변경 후 재접속하면 새 언어로 재고정" = **이미 지금 구현이 이 기준을 충족**(재접속=새 페이지로드=그 순간 `i18n.language`를 다시 읽어 지도 재요청, 로컬에서 새로고침 직후 정확한 언어로 뜨는 것 확인함). 언어 바뀔 때마다 지도를 그 자리에서 통째로 재로드하는 더 큰 수정은 **불필요 판단, 보류**.

**배포 후 재검증 필요**(로컬 dev와 실제 배포/실기기 환경 차이 가능성 = §11 정합):

- [ ] WebView(네이티브) 경로 = `itinerary-map-html.ts`도 같은 원리인지 실기기 확인(로컬은 웹 경로만 실증함)
